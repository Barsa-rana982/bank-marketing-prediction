# Bank Marketing Prediction

A machine learning project that predicts whether a client will subscribe to a term deposit based on data from direct marketing campaigns conducted by a Portuguese banking institution.

---

## Project Overview

This project covers a full data science pipeline:

| Task | Description |
|------|-------------|
| **1.1 – Data Preparation** | Load, inspect, and clean the dataset; handle 'unknown' values |
| **1.2 – EDA** | Explore key features (age, education, contact method, campaign outcome) with visualisations and statistical tests |
| **1.3 – Unsupervised Learning** | K-Means clustering to segment clients into 5 distinct groups |
| **1.4 – Supervised Learning** | Logistic Regression and KNN classifiers with hyperparameter tuning, confusion matrices, and ROC curve evaluation |

---

## Dataset

- **Source:** [UCI Machine Learning Repository – Bank Marketing](https://archive.ics.uci.edu/dataset/222/bank+marketing)
- **File:** `bank-full.csv`
- **Size:** 45,211 records × 17 features
- **Target variable:** `y` — whether the client subscribed to a term deposit (`yes` / `no`)

> The dataset is not included in this repository. Download `bank-full.csv` from the UCI link above and place it in the project root before running the notebook.

---

## Key Findings

- Clients with a **previous campaign success** are far more likely to subscribe again
- **Cellular contact** yields significantly higher subscription rates than telephone
- Clients at the extremes of age (under 30 and above 60) subscribe at higher rates than the middle group
- **Logistic Regression** achieved ~88% accuracy with a strong AUC, making it the recommended model for its interpretability and speed

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/bank-marketing-prediction.git
   cd bank-marketing-prediction
   ```

2. Download `bank-full.csv` from [UCI](https://archive.ics.uci.edu/dataset/222/bank+marketing) and place it in the project root.

3. Open the notebook:
   ```bash
   jupyter notebook Bank_MarketingPrediction.ipynb
   ```

4. Run all cells top to bottom (**Kernel → Restart & Run All**).
